# demo

한 문서가 어떻게 바뀌는지 보는 곳입니다.
`before.md` 는 손대기 전, `after.md` 는 `saramchae-ko` 를 적용한 뒤입니다.

```bash
python3 ../saramchae-ko/scripts/scan.py before.md
python3 ../saramchae-ko/scripts/scan.py after.md
```

## 스캐너가 무엇을 짚었나

| 검사 | before | after |
|---|---|---|
| 어체 | 평서체 1 / 존댓말 12 — 혼용 | 존댓말 13 — 일관 |
| 번역투 · 한자어 · 챗봇 잔여물 | 10 · 8 · 1 | 0 · 0 · 0 |
| 긴 문장 | 5 | 0 |
| 120자 초과 줄 | 2 | 0 |
| 목록 끝맺음 불일치 | 1 | 0 |
| 문장에 묻힌 열거 | L17 | 0 |
| 이모지 (헤딩 안) | 4 (2) | 0 (0) |
| 문장 단위 볼드 | 1 | 0 |
| **`total`** | **32** | **0** |

## 무엇이 그대로인가

숫자를 고친 것이 아니라 문장을 고친 것이라, 다음은 한 글자도 바뀌지 않았습니다.

- 측정 결과 표 5행
- `process()` 파이썬 코드 블록
- 인프라 팀 회신 인용문 — 원문 그대로 남겨야 하는 기록입니다
- `2,400ms`, `180ms`, `초당 40건`, `0.8%`, `0.3%`, `3회`, `이틀`, `멱등키`

## 무엇이 사라졌나

`분수령`, `중요한 역할을 하였음을 시사한다`, `극대화되었음을 확인할 수 있으며` 처럼 **재 볼 수 없는 문장**이 빠졌습니다.
그 자리에 남은 것은 `p95 응답시간이 2,400ms 에서 180ms 로 내려갔습니다` 한 줄입니다.
표에 이미 있는 사실이고, 확인할 수 있는 문장입니다.

`궁금한 점이 있으시면 언제든 편하게 문의해 주시기 바랍니다` 는 통째로 지웠습니다.
회고 문서가 독자에게 문의를 권하는 문장으로 끝날 이유가 없습니다.

## 무엇이 새로 생기지 않았나

없던 수치를 만들어 넣지 않았고, 어체를 평서체로 갈아치우지도 않았습니다.
원문이 존댓말 12 대 평서체 1 이었으므로 다수인 존댓말로 맞췄습니다.
**둘 다 교정이 아니라 다시 쓰기입니다.**
